# Інструкція з розгортання та запуску Genius.Space Downloader

Цей проект повністю автономний і призначений для завантаження навчальних курсів, відеолекцій (у високій якості 720p або 1080p), презентацій, прикріплених матеріалів та конспектів уроків з платформи **Genius.Space**.

---

## ⚡ Швидкий запуск на новому комп'ютері

### Крок 1. Перевірка / встановлення Python
1. Для роботи потрібен **Python 3.10** або новіший.
2. Якщо Python ще не встановлено:
   - Завантажте його з офіційного сайту: [python.org/downloads](https://www.python.org/downloads/)
   - **НАДЗВИЧАЙНО ВАЖЛИВО:** Під час встановлення на першому ж екрані обов'язково поставте прапорець **"Add python.exe to PATH"** (Додати Python до змінних середовища).

### Крок 2. Розпакування проекту
1. Розпакуйте архів у будь-яку зручну папку на диску (наприклад, `D:\Education\` або `C:\Tools\GeniusDownloader\`).
2. У папці обов'язково мають бути:
   - `bin\` (містить автономні `ffmpeg.exe` та `ffprobe.exe` для обробки відео)
   - `src\` (код модулів програми)
   - `main.py`, `run.bat`, `requirements.txt`, `.env`

### Крок 3. Запуск
1. Просто двічі клікніть файл **`run.bat`**.
2. При першому запуску скрипт **автоматично**:
   - створить локальне віртуальне середовище (`.venv`);
   - оновить `pip` та встановить усі необхідні бібліотеки (`requests`, `yt-dlp`, `rich`, `python-dotenv`);
   - перевірить наявність FFmpeg;
   - перевірить авторизацію та відкриє зручне інтерактивне меню.
3. Оберіть пункт **1** для завантаження курсу **No-Code Developer** або пункт **2** для перегляду та вибору будь-якого іншого вашого курсу (серед усіх доступних на акаунті).

## ⚙️ Налаштування та файл `.env`

У корені проекту знаходиться файл `.env`, де зберігаються всі параметри:

```ini
# Токен авторизації з браузера
GENIUS_AUTH_TOKEN=eiHWHZYBLAJsha3tFhNXseSJIJK_NVWiXOcp-YDX5ZTD5CZa

# Session-Id з браузера
GENIUS_SESSION_ID=d41fb6feebd5c6fbf133aefcc8ff7fca

# Slug курсу за замовчуванням
DEFAULT_COURSE_SLUG=nocodedeveloper

# Назва папки для збереження матеріалів
DEFAULT_COURSE_DIR=GeniusSpace_No-Code Developer

# Базова папка (. означає поточну папку)
DOWNLOAD_BASE_DIR=.

# Завантажувати відео (true/false)
DOWNLOAD_VIDEOS=true

# Завантажувати прикріплені файли та презентації (true/false)
DOWNLOAD_FILES=true

# Якість відео (720p, 1080p, 480p, best)
VIDEO_QUALITY=720p
```

### Як змінити якість відео:
- За замовчуванням встановлено **`VIDEO_QUALITY=720p`**.
- Якщо потрібно зберегти у найвищій роздільній здатності, змініть на `VIDEO_QUALITY=1080p` або `VIDEO_QUALITY=best`.
- Якщо потрібно максимально заощадити трафік/місце — встановіть `VIDEO_QUALITY=480p`.

## 🔑 Як оновити токен авторизації (якщо сесія закінчиться)

Сесійний токен Genius.Space зазвичай діє кілька днів або тижнів. Якщо термін дії вичерпався, програма повідомить про це: `[!] Токен застарів або недійсний`.

**Щоб отримати свіжий токен:**
1. Відкрийте браузер (Chrome / Edge / Firefox) та увійдіть до кабінету: `https://edu.genius.space/courses/nocodedeveloper`
2. Натисніть **F12** (відкриються інструменти розробника).
3. Перейдіть на вкладку **Network** (Мережа).
4. Оновіть сторінку клавішею **F5**.
5. У рядку фільтра (Filter) введіть `nocodedeveloper`.
6. Клацніть на будь-який запит до `course.genius.space`.
7. У блоці **Request Headers** (Заголовки запиту) знайдіть:
   - `authorization`: скопіюйте довгий рядок після слова `Bearer ` (наприклад, `eiHWHZYBL...`)
   - `session-id`: скопіюйте 32-значний хеш (наприклад, `d41fb6feebd5...`)
8. Вставте їх у файл `.env` (або просто введіть у консоль при запуску `run.bat`).

## 💡 Корисні особливості
- **Resume (Докачування):** Якщо завантаження було перервано або ви перезапустили скрипт, він автоматично перевіряє розмір уже завантажених відео (> 1 MB) і пропускає їх, продовжуючи з місця зупинки.
- **Вбудований FFmpeg:** Бінарники `ffmpeg.exe` та `ffprobe.exe` вже знаходяться всередині папки `bin/`, тому не потрібно нічого налаштовувати в системних змінних Windows.
